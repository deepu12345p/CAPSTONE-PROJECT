## 🌟 Project Overview

This capstone project is an interactive **Sales and Profit Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard uses the Global Superstore dataset to analyze business performance through interactive charts, graphs, KPIs, and filters.

It helps users understand sales trends, profit performance, customer activity, product categories, and shipping methods.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Track total revenue and profit.
- Understand customer and order statistics.
- Compare sales and profit across different years.
- Analyze sales across product categories.
- Identify profit performance by shipping mode.
- Explore business performance using interactive filters.

## 📈 Dashboard Features

### 1. Key Performance Indicators (KPIs)

The dashboard displays the following important metrics:

- 💰 Revenue
- 📊 Total Profit
- 👥 Number of Customers
- 📦 Total Orders
- 📈 Average Profit Percentage

### 2. Sales Analysis

- Year-on-Year Sales Analysis
- Category-Wise Sales Analysis
- Sales performance across different years

### 3. Profit Analysis

- Year-on-Year Profit Analysis
- Profit by Shipping Mode
- Comparison of business profitability

### 4. Interactive Filters

The dashboard includes the following filters:

- Order Year
- Sub-Category
- Market
- Category

### 5. Order Details

The dashboard includes an order details table containing:

- Customer ID
- Country
- Order Year
- Order Month
- Order ID
- Sales

## 📂 Dataset Description

The project uses the Global Superstore dataset, which contains information about customer orders, sales, profits, products, markets, and shipping methods.

Important dataset fields:

- Order Date
- Sales
- Profit
- Customer ID
- Order ID
- Country
- Market
- Category
- Sub-Category
- Ship Mode

## 🚀 How to Open the Project

1. Install Microsoft Power BI Desktop.
2. Download the `.pbix` project file.
3. Open Microsoft Power BI Desktop.
4. Select **File → Open**.
5. Choose `dashboard creation.pbix`.
6. Wait for the dashboard to load.
7. Use the filters and charts to explore the data.
